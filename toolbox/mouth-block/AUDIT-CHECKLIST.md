## DOCTRINE

The mouth-block script silences packages. What it cannot reach — background data, battery freedom, notification chatter — lives behind Settings toggles that belong to the owner's hand alone. This checklist is advice, struck in order, each pass reversible by walking it backwards. The desk advises; it never flips a setting on the founder's phone.

**The never-touch list governs here too:** nothing in this checklist touches KeyMint/Keystore, Gatekeeper/Weaver, the TEE stack, the Knox platform, radio/baseband, or the storage and display HALs. Block the mouth, not the Vault.

## PASS 0 — THE BASELINE

- [ ] Run `permission-audit.sh` and keep the dated file. This is the before-picture; every later claim about what the block did is judged against it.

## PASS 1 — THE BLOCK

- [ ] Read `packages.tsv` whole — every default row, every note.
- [ ] `sh mouth-block.sh` (dry run). Read every BLOCK/UNDO pair aloud.
- [ ] `sh mouth-block.sh --apply`. Keep the state log it writes; the log is the undo's memory.
- [ ] Walk the review tier by eye. Only what the founder himself rules goes in with `--include-review`.

## PASS 2 — BACKGROUND DATA (per surviving Samsung consumer app)

Settings → Apps → (app) → Mobile data:

- [ ] **Allow background data usage — OFF** for: Galaxy Store (if it survived review), Samsung Members, Samsung Free, Samsung Cloud (if kept), Samsung Health (if kept).
- [ ] Leave radio, telephony, and every system service untouched — this pass is for consumer surfaces only.

## PASS 3 — BATTERY FREEDOM

Settings → Battery and device care → Battery → Background usage limits:

- [ ] Put the surviving promotion/push surfaces under **Sleeping** or **Deep sleeping** as the unit offers.
- [ ] Never restrict: the PQVTPM client (when it lands), the tailnet agent, the phone's serving apps, messaging the founder relies on. A silenced phone that misses its own calls has traded the wrong mouth.

## PASS 4 — PERMISSIONS, BY EYE

Settings → Apps → (app) → Permissions, for each manifest package still enabled:

- [ ] Location, Contacts, Phone, SMS, Microphone, Camera: each grant should have a reason the founder can say out loud. No reason — revoke.
- [ ] "Appear on top" and "Install unknown apps": OFF for every consumer surface, no exceptions argued.

## PASS 5 — THE PROOF

- [ ] Run `permission-audit.sh` again. Diff it against the Pass 0 baseline: the blocked set shows DISABLED, the never-touch set shows present and enabled, nothing else moved.
- [ ] Restart the unit once. Confirm: calls land, Keystore-backed apps (banking, Pass if kept) still unlock, the Vault still stands. If anything in the protected stack misbehaves, undo first (`sh mouth-block.sh --undo`), diagnose second.

## UNDO

- [ ] `sh mouth-block.sh --undo` restores exactly what the state log recorded. The checklist passes walk backwards the same way. Nothing in this kit is a one-way door — that is the design, stated so it can be checked.
